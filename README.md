# 危机路径终极看板

这是一份教学用的情景比较看板，不是预测，也不是投资建议。

用 GitHub Pages 打开后，页面会自动读取同目录下的 `snapshot.json`。每天更新这份判断稿后，打开网页即可同步，确认后再采用勾选。判断稿仍是 version 1；只有 12 项或 19 项的旧稿也可以继续用，缺的新项会显示为证据不足，不会编造当天行情。采用后只改诊断勾选，不会自动选定路径。

页面分成诊断、看板、策略、对照、说明五个屏，用底部栏切换；默认打开看板。诊断在采用当天判断后，会显示跨行业的全局判断，并核对应就业、房地产、银行、出口，以及利率、金融条件和物价等用于区分路径的现象。
